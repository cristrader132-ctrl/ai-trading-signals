# AI Trading Signals OTC — prototipo v1

Aplicación web educativa para probar la interfaz en modo demo.

## Ejecutar
- Requiere Node.js 18 o superior.
- Ejecuta `npm start` o `node server.js`.
- Abre `http://localhost:3000`.

## Importante
Esta versión no se conecta a IQ Option, no obtiene cotizaciones OTC reales y no ejecuta operaciones. El gráfico es sintético y la señal permanece en `NO OPERAR`. Para una versión real se necesita una fuente de datos OTC auténtica y autorizada, y validación independiente. No introduzcas contraseñas, cookies ni códigos de IQ Option en este proyecto.
